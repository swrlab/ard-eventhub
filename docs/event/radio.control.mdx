Dieses Event ist für Eventhub Connect vorgesehen und wird über `POST /events/de.ard.eventhub.v1.radio.control` mit HTTP 400 abgelehnt. Der Publisher schreibt es auf `inbox/{institutionId}`. Nach der Eventhub Validierung liegt es retained auf `radio/{livestreamId}/control`.

`services[]` ist URN-only (`id`, `publisherId` und `institutionId` als `urn:ard:…`). `start` ist ISO8601. `creator` setzt der Publisher. `created` setzt die Eventhub Validierung auf den Zeitpunkt der Zustellung und überschreibt einen mitgeschickten Wert.

`name` ist `TA` oder `REGIO`. `details` ist ein optionaler String.

## Beispiel

**Minimal** setzt die Pflichtfelder. **Maximal** ist der Diff dagegen und markiert `validUntil` und `details`. `created` setzt die Eventhub Validierung.

### Minimal

```json
{
	"event": "de.ard.eventhub.v1.radio.control",
	"start": "2026-05-27T16:03:00+01:00",
	"name": "TA",
	"state": true,
	"services": [
		{
			"publisherId": "urn:ard:publisher:75dbb3dace15f610",
			"institutionId": "urn:ard:institution:a3004ff924ece1a2",
			"id": "urn:ard:permanent-livestream:49267f7d67be180d"
		}
	],
	"creator": "example@swr.de"
}
```
